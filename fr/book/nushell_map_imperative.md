# Carte Nushell des langages impératifs

L'idée derrière ce tableau est de vous aider à comprendre comment les intégrés et plugins Nushell se rapportent aux langages impératifs. Nous avons essayé de produire une carte des commandes Nushell pertinentes à la programmation et quels sont leurs équivalents dans d'autres langages. Les contributions sont bienvenues.

Remarque : ce tableau suppose Nushell 0.94 ou version ultérieure.
