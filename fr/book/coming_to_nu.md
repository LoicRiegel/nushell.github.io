# Venir à Nu

Si vous êtes familier avec d'autres shells ou langages de programmation, vous pourriez trouver ce chapitre utile pour vous mettre à jour rapidement.

[Venir de Bash](coming_from_bash.md) montre comment certains motifs typiques pour Bash, ou les shells POSIX en général, peuvent être mappés à Nushell.
De même, [Venir de CMD.EXE](coming_from_cmd.md) montre comment les commandes intégrées dans l'invite de commande Windows peuvent être mappées à Nushell.

Des comparaisons similaires sont faites pour certains [autres shells et langages spécifiques au domaine](nushell_map.md), [langages impératifs](nushell_map_imperative.md) et [langages fonctionnels](nushell_map_functional.md).
Une comparaison séparée est faite spécifiquement pour [les opérateurs](nushell_operator_map.md).
