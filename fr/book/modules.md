# Modules

Comme de nombreux langages de programmation, Nushell supporte l'écriture et l'utilisation de _modules_ comme un moyen d'organiser le code plus efficacement. Les modules peuvent être considérés comme des « conteneurs » qui contiennent diverses définitions, notamment :

- Commandes personnalisées supplémentaires
- Alias
- Constantes
- Externs
- Variables d'environnement
- Et même d'autres modules (a.k.a., sous-modules)

De nombreux utilisateurs commenceront par utiliser des modules écrits par d'autres, puis progresseront vers l'écriture de leurs propres. Ce chapitre couvre ces deux sujets :

- [Utilisation de modules](./modules/using_modules.md)
- [Création de modules](./modules/creating_modules.md)
